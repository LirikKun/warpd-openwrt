# warpd

[English](README.md)

Панель управления WARP-прокси для OpenWrt. Создавайте SOCKS-профили, находите рабочие эндпоинты и проверяйте соединения через встроенный веб-интерфейс, не меняя сетевые настройки роутера.

## Возможности

- Несколько профилей WARP / AmneziaWG (AWG), MASQUE QUIC/H2 и Relay-WARP.
- Компактная веб-консоль в стиле TUI: «Прокси», Relay, «Поиск», «Настройки»; черновики сохраняются при переходах.
- Явное действие «Переименовать», отдельные порты, настройки эндпоинтов и переключатели профилей.
- Три режима географии для каждого профиля: выключена, исключения или строгая выбранная страна публичного IP.
- Автоматический поиск эндпоинтов, ручное закрепление адреса и проверка доступности.
- Активация и мониторинг IP Relay, при необходимости — связанные туннельные профили.
- Русский и английский интерфейс; для загрузки панели не нужны внешние веб-сервисы.

warpd не меняет маршруты, firewall, DNS роутера или настройки SSClash и не перенаправляет весь трафик автоматически. Комплектные Mihomo и WarpScout устанавливаются в отдельный каталог warpd; существующие общие бинарники не перезаписываются.

## Установка и обновление

Нужны **OpenWrt arm64 или amd64**, доступ root по SSH, работающий HTTPS и свободное место в хранилище и RAM для распаковки. Подключитесь к роутеру как root, заменив адрес своим:

```sh
ssh root@192.168.10.1
```

Для **первой установки и обновления используется одна и та же команда**:

```sh
wget -T 30 -qO- https://github.com/LirikKun/warpd-openwrt/raw/refs/heads/main/install-warpd.sh | ash
```

Установщик определит архитектуру, проверит требования и SHA-256 скачанного комплекта. Перед установкой недостающих зависимостей через настроенные репозитории `apk`/`opkg` он запросит согласие и предложит язык интерфейса: **English / Русский**.

При обновлении сохраняются настройки, аккаунты, профили и текущий язык, если вы не выберете другой. Прокси-соединения ненадолго прервутся. **Для обычного обновления новый аккаунт не нужен.**

Перед обновлением сохраните приватную копию этих файлов вне роутера, если они существуют:

- `/etc/config/warpd` — настройки.
- `/etc/warpd/warp-account.json` — общий аккаунт WARP.
- `/etc/warpd/profiles.json` — профили и учётные данные Relay.

Старые настройки профилей переносятся при первом запуске. Откат одного бинарника не отменяет перенос. [Файлы и описание релиза](https://github.com/LirikKun/warpd-openwrt/releases/tag/v3.1.0).

## Первый запуск

1. Откройте в браузере `http://<LAN-IP-роутера>:9095/`.
2. После чистой установки есть **один профиль WARP на порту 4001**, но аккаунт ещё не создан.
3. Откройте **«Настройки» → «Диагностика и журнал» → «Обслуживание аккаунта · опасные действия» → «Новый аккаунт»**. Подтвердите действие и дождитесь успешной регистрации в журнале.
4. Если поиск эндпоинтов не начался, откройте **«Поиск» → «Найти для всех»**. Перед подключением клиентов дождитесь готовности профиля.
5. Остальные профили создаются через **«Добавить прокси»**, каждый со своим портом. Существующие установки сохраняют свои профили и порты.

Для регистрации и поиска нужен доступ во внешнюю сеть. Пока профиль не готов, его SOCKS-порт закрыт; смотрите состояние и журнал в панели.

### Политика географии

В **расширенных настройках** профиля режим **«выключена»** отключает только географические ограничения; **«исключения»** запрещает исключённые наблюдаемые узлы, страны узлов и публичного IP; **строгий** дополнительно требует выбранную страну публичного IP, подтверждённую свежей независимой геолокацией и согласующимся текущим результатом `/meta`. Неизвестные обязательные или противоречивые данные блокируют доступ. Проверки транспорта и учётных данных действуют во всех режимах. Проверки периодические: смена страны обнаруживается не мгновенно. Профили без явно выбранного режима сохраняют прежнее поведение до его изменения. Страна сервера Relay — не целевая страна публичного IP.

## Подключение клиента

В приложении укажите SOCKS5-прокси с LAN-адресом роутера и портом профиля. Для начального WARP это `LAN-IP-роутера:4001`.

Используйте **разрешение имён через SOCKS** (`socks5h`), чтобы адрес назначения определял сам прокси. Например, с компьютера, где установлен curl:

```sh
curl --proxy socks5h://192.168.10.1:4001 --noproxy '' \
  --connect-timeout 12 --max-time 25 https://ifconfig.co/json
```

SOCKS поддерживает **только TCP CONNECT, без UDP и BIND**. Поддержка MASQUE QUIC не добавляет UDP для SOCKS-клиентов. Перезапуск или перенастройка общего движка могут ненадолго затронуть другие профили.

## Настройка Relay

1. В разделе **«Relay → Добавить Relay»** сохраните **выключенный** ресурс с приватной ссылкой активации. Перед включением откройте **расширенные настройки**, задайте исходный IP/интерфейс, проверьте внешний IP и подтвердите общий исходящий путь активации и туннеля. Сохранение одной ссылки не настраивает этот путь автоматически. Не публикуйте ссылку и не открывайте её с другого устройства.
2. Создайте **выключенный профиль Relay-WARP**, связанный с этим ресурсом; выберите страну сервера и SOCKS-порт. Страна сервера не гарантирует страну выхода.
3. В разделе профиля **«Аккаунт туннеля · только этот профиль»** вручную введите назначенные учётные данные либо явно подтвердите **«Зарегистрировать новый аккаунт»**. Они не связаны с общим WARP-аккаунтом.
4. Включите **сначала родительский ресурс Relay, затем дочерний профиль**. Включение родителя может отправить провайдеру запросы активации. Дождитесь готовности профиля: сохранение настроек ещё не означает работающий туннель.
5. Подключайтесь через `socks5h://<LAN-IP-роутера>:<порт-профиля>`, передавая имена хостов, а не уже разрешённые локально адреса.
6. Для остановки **выключите дочерний профиль до родителя**. Выключение только родителя приостанавливает связанные профили, сохраняя их выбор включения; пока родитель выключен, переключатели дочерних профилей заблокированы.

Работа Relay зависит от провайдера и исходящего соединения. Успешный ответ активации ещё не означает готовность туннеля. [Подробная справка Relay](docs/relay-runtime-integration.md) (англ.).

## Доступ и приватные данные

**Используйте только в доверенной LAN.** По умолчанию панель/API слушает `0.0.0.0:9095` без API-токена, а SOCKS не требует аутентификации. WAN-порты не открываются, но вы должны исключить доступ из Интернета и недоверенных сетей.

Адрес управления можно ограничить через `web_listen`, а API защитить параметром `warpd.global.web_secret`; после внешнего изменения этих настроек нужен перезапуск. **API-токен не защищает SOCKS.** Не публикуйте аккаунты, хранилище профилей, ссылки активации и резервные копии.

## Удаление

Удалить warpd, **сохранив настройки, аккаунты и профили**:

```sh
warpd-uninstall
```

Дополнительно удалить сохранённые настройки и учётные данные:

```sh
warpd-uninstall --purge
```

`--purge` удаляет ровно эти файлы данных: `/etc/config/warpd`, `/etc/warpd/warp-account.json` и `/etc/warpd/profiles.json`. При необходимости заранее сделайте копию. Внешние общие бинарники, SSClash и общие системные пакеты не удаляются.
