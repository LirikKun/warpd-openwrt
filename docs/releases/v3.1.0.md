# warpd v3.1.0

[English guide](https://github.com/LirikKun/warpd-openwrt/blob/main/README.md) · [Русское руководство](https://github.com/LirikKun/warpd-openwrt/blob/main/README.ru.md)

## English

- Compact TUI-style web console with Proxies, Relay, Search and Settings; navigation keeps drafts, and each proxy has an explicit Rename action.
- Three per-profile geography modes: off (geography only), exclusions, and strict selected public-IP country. Strict requires fresh independent geolocation and an agreeing current `/meta` result, while still applying exclusions. Checks are periodic, not instant; existing profiles without a mode keep compatibility behavior.
- Relay links can be saved disabled. Configure and acknowledge the outgoing path before enabling; automatic path selection is not implemented. Server country is not the strict public-IP target.

## Русский

- Компактная веб-консоль в стиле TUI: «Прокси», Relay, «Поиск», «Настройки». Переходы сохраняют черновики; у профиля есть явное действие «Переименовать».
- Три режима географии профиля: выключена (только география), исключения и строгая выбранная страна публичного IP. Строгий режим требует свежей независимой геолокации и согласующегося текущего `/meta`, сохраняя исключения. Проверки периодические, не мгновенные; профили без режима сохраняют прежнее поведение.
- Ссылку Relay можно сохранить с выключенным ресурсом. Перед включением настройте и подтвердите исходящий путь: автоматического выбора пока нет. Страна сервера не задаёт строгую страну публичного IP.

## Install or upgrade / Установка и обновление

Run as root over SSH on OpenWrt arm64/amd64. / Выполните от root по SSH на OpenWrt arm64/amd64:

```sh
wget -T 30 -qO- https://github.com/LirikKun/warpd-openwrt/raw/refs/heads/main/install-warpd.sh | ash
```

Settings and accounts are preserved; back up first. Proxy connections briefly restart. / Настройки и аккаунты сохраняются; заранее сделайте копию. Прокси-соединения ненадолго прервутся.

Relay: [llimonix](https://github.com/nellimonix) · [warp-config-generator-vercel](https://github.com/nellimonix/warp-config-generator-vercel).
