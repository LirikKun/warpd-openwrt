## English

- Rename is now inside each profile's collapsed **Connection and details** section. It opens Advanced and selects the name; saving changes only that profile.
- Thanks to [llimonix](https://github.com/nellimonix) for the external Relay service. warpd uses its own client implementation; no code from the service's project is included.

## Русский

- Действие «Переименовать» перенесено в свёрнутый раздел **«Подключение и детали»** профиля. Оно открывает расширенные настройки и выделяет имя; сохранение меняет только этот профиль.
- Благодарим [llimonix](https://github.com/nellimonix) за внешний Relay-сервис. warpd использует собственную клиентскую реализацию; код проекта сервиса не включён.

## Install or upgrade / Установка и обновление

Run as root over SSH on OpenWrt arm64/amd64. / Выполните от root по SSH на OpenWrt arm64/amd64:

```sh
wget -T 30 -qO- https://github.com/LirikKun/warpd-openwrt/raw/refs/heads/main/install-warpd.sh | ash
```

Settings and accounts are preserved; back up first. Proxy connections briefly restart. See the guides above for first use and Relay setup. / Настройки и аккаунты сохраняются; заранее сделайте копию. Прокси-соединения ненадолго прервутся. Первый запуск и настройка Relay описаны в руководствах выше.
