# warpd v3.0.0

[English guide](https://github.com/LirikKun/warpd-openwrt/blob/main/README.md) · [Русское руководство](https://github.com/LirikKun/warpd-openwrt/blob/main/README.ru.md)

## English

- Create and manage multiple WARP/AWG, MASQUE QUIC/H2 and Relay-WARP profiles.
- Separate Relay activation and IP monitoring, with profile-owned tunnel accounts.
- English/Russian web UI with endpoint discovery and connection status.
- Fixed Relay destination DNS resolution when the router uses Fake-IP.

## Русский

- Создание и управление несколькими профилями WARP/AWG, MASQUE QUIC/H2 и Relay-WARP.
- Отдельные активация и мониторинг IP Relay, собственные аккаунты туннельных профилей.
- Русский/английский интерфейс с поиском эндпоинтов и состоянием соединений.
- Исправлено разрешение имён через Relay при использовании Fake-IP на роутере.

## Install or upgrade / Установка и обновление

Run as root over SSH on OpenWrt arm64/amd64. / Выполните от root по SSH на OpenWrt arm64/amd64:

```sh
wget -T 30 -qO- https://github.com/LirikKun/warpd-openwrt/raw/refs/heads/main/install-warpd.sh | ash
```

Upgrades keep settings and accounts. Back up first; proxy connections briefly restart. / Настройки и аккаунты сохраняются. Заранее сделайте копию; прокси-соединения ненадолго прервутся.

## Uninstall / Удаление

`warpd-uninstall` keeps saved data. Use `warpd-uninstall --purge` to also delete settings, accounts and profiles. / `warpd-uninstall` сохраняет данные. Для удаления вместе с настройками, аккаунтами и профилями — `warpd-uninstall --purge`.
