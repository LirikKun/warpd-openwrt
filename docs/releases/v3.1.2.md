# warpd v3.1.2

## English

- Installation streams verified payloads from the compressed archive into destination-side staging, avoiding a full unpacked copy in `/tmp` while retaining integrity checks and rollback.
- Both arm64 and amd64 have four bundles: `full`, `no-mihomo`, `no-warpscout` and `core`. Explicit `--mihomo /absolute/path/to/mihomo` and/or `--warpscout /absolute/path/to/warpscout` select the matching smaller bundle; `core` requires both. Shared executables remain untouched. There is no separate on-demand dependency download.
- Upgrades preserve settings, accounts, profiles and UI language unless explicitly changed. Language edits use bounded streaming processing instead of keeping the whole configuration in memory.

The full bundle's initial checks require 41 MiB free in `/tmp` and, separately, 49 MiB available memory. Persistent payload and rollback space are still required; these are planning checks, not a total-RAM guarantee. Smaller bundles have smaller initial gates; see the [storage and memory details](https://github.com/LirikKun/warpd-openwrt/blob/main/docs/packaging-integration.md#archive-backed-installation-new-bundle-format-support).

Install or upgrade using the unchanged command on the router:

```sh
wget -T 30 -qO- https://github.com/LirikKun/warpd-openwrt/raw/refs/heads/main/install-warpd.sh | ash
```

[Setup and reuse instructions](https://github.com/LirikKun/warpd-openwrt/blob/main/README.md#install-and-upgrade).

## Русский

- Установка передаёт проверенные файлы из сжатого архива во временные файлы на целевом хранилище без полной распаковки в `/tmp`, сохраняя проверки целостности и откат.
- Для arm64 и amd64 доступны четыре комплекта: `full`, `no-mihomo`, `no-warpscout` и `core`. Явные флаги `--mihomo /absolute/path/to/mihomo` и/или `--warpscout /absolute/path/to/warpscout` выбирают меньший комплект; для `core` нужны оба. Общие бинарники не изменяются. Отдельной загрузки зависимостей по требованию нет.
- Обновление сохраняет настройки, аккаунты, профили и язык интерфейса, если вы явно не меняете их. Изменение языка обрабатывается потоково с ограничениями, без хранения всей конфигурации в памяти.

Начальные проверки полного комплекта требуют 41 MiB свободного места в `/tmp` и отдельно 49 MiB доступной памяти. Место для устанавливаемых файлов и копий отката по-прежнему необходимо; эти проверки не гарантируют общее потребление RAM. Для меньших комплектов начальные пороги ниже; [подробнее](https://github.com/LirikKun/warpd-openwrt/blob/main/docs/packaging-integration.md#archive-backed-installation-new-bundle-format-support) (англ.).

Для установки и обновления используйте ту же команду выше. [Инструкция и повторное использование бинарников](https://github.com/LirikKun/warpd-openwrt/blob/main/README.ru.md#установка-и-обновление).
